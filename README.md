🛒 E-Commerce Platform

Modern. Scalable. Seamless Shopping Experience.

A full-featured e-commerce platform built with Laravel 10, Livewire, Filament, Preline UI, and Tailwind CSS.
Designed to deliver a smooth shopping journey with powerful admin tools and a clean, responsive interface.

✨ Features

🔐 Secure Authentication & Roles – Admin & Customer

📦 Product & Inventory Management with Filament

🛍️ Shopping Cart & Checkout Flow

📑 Order Tracking & Management (Customer + Admin views)

💳 Payment Integration Ready

🖼️ Browse by Brand & Category

🎨 Responsive & Modern UI (TailwindCSS + Preline UI)

⚡ Reactive Components powered by Livewire

🛠️ Tech Stack

Laravel 10 – Elegant PHP framework

Livewire – Reactive UI without JavaScript

Filament – Powerful admin panel

Tailwind CSS – Utility-first CSS framework

Preline UI – Tailwind-based UI kit

Manage products, categories, brands, and orders with ease.
